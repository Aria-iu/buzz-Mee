# `.pi` Agent 工作区

本目录是此 Buzz fork 的 Agent 专用记录区，与原项目源代码和上游文档隔离。

## 允许保存的内容

- `knowledge/`：有仓库证据支撑的项目理解。
- `decisions/`：项目所有者批准进入开发后形成的架构决策。
- `plans/`：经过确认的调研或开发计划。
- `reports/`：阶段报告、变更摘要和测试结果。
- `local/`：原始日志、临时输出和中间产物；除 `.gitkeep` 外均由 `.pi/.gitignore` 忽略。

## 强制边界

1. 调研阶段仅更新 `.pi/`；进入开发后，只有在项目所有者明确批准的范围内才修改产品文件。
2. 中文叙述为主，代码符号、路径和协议名保留英文。
3. 稳定文档必须引用仓库内证据路径，并区分愿景、当前实现和推断。
4. 不在可跟踪文档中保存密钥、令牌、完整环境变量、数据库内容或原始会话流水。
5. 未经项目所有者明确要求，不执行 `git commit` 或远程推送。
6. 后续功能代码必须进入 Buzz 既有模块；`.pi/` 只保存 Agent 工作记录。
