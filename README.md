# Medical Agent

面向多 Agent 协作、Pipeline 设计与医疗人工智能研究的平台。

## 项目目标

本项目关注的不是单个 Agent 能完成多少任务，而是多个具备不同能力、角色和知识来源的 Agent 如何交流、协作、质疑和验证彼此的结论。

项目将研究和实现可配置、可复现、可评估的多 Agent Pipeline，使开发者能够调整 Agent 角色、交互协议、执行顺序、证据传递、分歧处理和结果验证方式，并通过实验持续优化整个 Pipeline，而不是只替换某一个模型。

## 主要研究方向

### Agent 之间的交互

- 定义结构化的 Agent 消息、任务、证据、意见和决策记录。
- 支持协作、辩论、交叉检查、反思、验证和失败升级等交互方式。
- 保存每个 Agent 的输入、输出、工具调用和推理依据，形成可追踪的执行过程。
- 研究不同角色划分、通信拓扑和共识机制对最终结果的影响。

### Multi-Agent Pipeline

- 使用可配置的 Pipeline 组织多个专业 Agent。
- 支持串行、并行、分层和带反馈回路的执行结构。
- 对 Pipeline 的准确性、稳定性、成本、延迟和可解释性进行评估。
- 支持对 Agent 组合、Prompt、模型、工具和交互轮次进行对比实验与优化。
- 将通用 Pipeline 能力设计为可复用模块，以支持医疗之外的其他领域。

### 医疗 Agent 与癌症 WSI 研究

本项目的重点应用方向是医疗人工智能，尤其是癌症病理全切片图像（Whole Slide Image，WSI）的多 Agent 分析与辅助诊断研究。

计划探索由不同专业 Agent 共同参与的工作流，例如：

```text
WSI输入
  → 图像质量控制与预处理
  → 组织和候选区域识别
  → 多个病理图像分析Agent并行分析
  → 医学知识与病例信息Agent提供上下文
  → 验证Agent检查证据、分歧与不确定性
  → 人类专家复核
  → 生成带证据来源的研究报告
```

研究重点包括：

- 如何让不同Agent共享切片区域、特征、证据和不确定性；
- 如何处理多个Agent之间相互矛盾的判断；
- 如何通过Pipeline优化提升结果的可靠性和可复现性；
- 如何记录模型、数据、参数和执行过程，支持审计与实验比较；
- 如何将人类病理专家保留在最终审核与决策环节。

## 当前状态

`medical-agent`是本项目的主要开发分支。项目目前处于早期研究和基础设施建设阶段，后续将逐步实现Agent通信协议、Pipeline编排、实验评估、WSI数据接口和医疗领域Agent。

> **研究用途声明：** 本项目目前仅用于研究和软件开发，不是医疗器械，不能替代合格医生、病理专家的诊断、复核或临床决策。
